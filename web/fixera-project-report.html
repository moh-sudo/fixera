1. Project Overview
What Fixera is and how it works
💡
What is Fixera?
Fixera is a two-sided home services marketplace in Nairobi, Kenya. Customers book verified professionals (plumbers, electricians, painters, cleaners) directly from their phone or browser. Workers receive job alerts, navigate to the customer's location via live GPS map, complete the job, and get paid. The admin team reviews worker documents and manages the entire platform from a single dashboard.

8. What's Remaining
Ordered by priority — High / Medium / Low
High Priority Medium Priority Nice to Have
💳 M-Pesa Payment Integration
The payment page currently has a UI only — no real money moves. Need to connect Safaricom Daraja API (STK Push) so customers can pay directly from M-Pesa.
  • Safaricom Daraja API account
  • STK Push edge function
  • Payment confirmation webhook
  • Update booking status on payment
💰 Real Pricing System
Job amounts are hardcoded at KSh 1,500. Need a proper pricing engine based on service type, sub-service, and duration. Worker earnings should calculate automatically.
  • pricing table in DB per sub-service
  • Dynamic amount on receipt
  • Worker gets 85%, platform 15%
  • Earnings page pulling real data
🔔 Push Notifications
Workers currently have to refresh to see new jobs. Customers don't get notified when a worker accepts or arrives. Need real-time push alerts on both sides.
  • Supabase Realtime job alerts for workers
  • Customer notification when worker accepts
  • Notification when worker on way / arrived
  • Browser push or in-app bell icon
🤖 Fixera AI Assistant
The AI chat bubble is already in the customer app UI but the backend is not connected. It should answer questions about services, help pick the right professional, and give pricing estimates.
  • Connect Gemini or OpenAI API
  • System prompt with Fixera context
  • Edge function to proxy AI calls
  • Chat history saved per session
⭐ Worker Rating System
Customers can submit a review after a job, but the worker's average rating on their profile isn't being auto-updated from the reviews table.
  • Trigger or function to avg ratings
  • Update workers.rating after each review
  • Display rating stars on BookingFormPage
  • Sort workers by rating in booking form
📸 Storage Buckets Setup
Two storage buckets are referenced in the onboarding code but may not be created in Supabase yet. Worker documents and profile photos won't upload without them.
  • Create worker-profiles bucket (public)
  • Create worker-documents bucket (private)
  • Verify receipts bucket exists (public)
  • Set correct RLS policies on each
📜 Booking History Pricing
BookingHistoryPage shows all bookings but no prices. After the pricing system is built, each booking card should show what was charged.
  • Join bookings with receipts table
  • Show amount on each history card
  • Add total spent summary at top
🔍 Admin: Worker License Verify
Admin can see worker documents (ID photo, ERB number etc) but there's no direct link to verify licenses against the ERB Kenya public portal or EPRA registry.
  • External link to ERB Kenya portal
  • Admin verification notes field
  • Verified badge on worker profile
