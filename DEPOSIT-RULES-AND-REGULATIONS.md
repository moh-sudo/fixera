## 🏦 DEPOSIT OVERVIEW

### **What is the Deposit?**

The **KSh 500 Worker Wallet Deposit** is:
- ✅ A **security deposit** (like rental/Uber driver background)
- ✅ A **verification mechanism** (proof of identity + commitment)
- ✅ An **escrow account** (held by Fixera, not worker's money)
- ✅ A **fraud deterrent** (consequence for rule-breaking)

### **Purpose**
```
Protect:
├─ Customers (from bad workers)
├─ Fixera (from chargebacks, fraud)
├─ Good workers (from unfair disputes)
└─ Platform (from abuse)
```

### **Legal Basis**
- Fixera Terms of Service (Section 7: Wallet Deposit)
- Kenya Consumer Protection Act 2012
- Kenya Unfair Contract Terms Act 1977
- Fixera's anti-fraud policy

├─ ID number uniqueness (no duplicates)
├─ ID expiry date (valid only)
├─ Age validation (18+ only)

```

## 🔒 DEPOSIT HOLD PERIOD

### **When is Deposit Released?**

**Rule 1: 30-Day Initial Hold (Non-Refundable)**
```
Duration: First 30 calendar days after deposit
Status: HELD (Fixera keeps it, not accessible)
Reason: 
├─ Verification period
├─ Chargeback window (M-Pesa chargebacks)
├─ Fraud investigation time
└─ Platform security

During 30 Days:
├─ Worker CAN:
│  ├─ Accept jobs ✓
│  ├─ Earn commission ✓
│  ├─ Withdraw earnings ✓
│  └─ Use platform normally ✓
├─ Worker CANNOT:
│  ├─ Withdraw deposit ✗
│  ├─ Close account ✗
│  └─ Get refund ✗
└─ If violation detected:
   └─ Deposit FORFEITED (not returned)

Example:
├─ Deposit paid: June 5, 2026
├─ Hold until: July 5, 2026
└─ First refund eligibility: July 6, 2026
```

**Rule 2: After 30 Days - What Happens**

```
DEPOSIT STATUS CHANGES:
├─ Day 31: Deposit becomes "Refundable" (if no violations)
├─ Wallet shows: "Deposit: KSh 500 (Refundable)"
└─ Worker can request refund anytime after Day 31

CONDITIONS FOR REFUND:
├─ ✓ No active disputes
├─ ✓ No chargebacks filed
├─ ✓ No pending investigations
├─ ✓ No violations detected
├─ ✓ Account in good standing
└─ ✓ No holds on wallet

REFUND PROCESS (After Day 31):
├─ Worker: "Request refund of deposit"
├─ System: Checks conditions above
├─ If OK: 
│  ├─ Deposit amount returned via M-Pesa
│  ├─ Refund processed within 24h
│  └─ Worker notified: "KSh 500 refunded to M-Pesa"
└─ If NOT OK:
   ├─ Reason shown to worker
   ├─ Options: Wait for dispute resolution OR appeal
   └─ Worker can reapply after issue resolved
```

## 🚨 FORFEITURE CONDITIONS

### **When is Deposit FORFEITED? (NOT Refunded)**

The deposit is **permanently lost** if any of these occur:

#### **CATEGORY 1: Fraud & Deception**

```
1. FAKE IDENTITY
├─ Using false national ID ❌
├─ Using someone else's ID ❌
├─ ID tampering/editing ❌
├─ Multiple accounts (same person) ❌
└─ FORFEITURE: 100% + Account BANNED

2. PAYMENT FRAUD
├─ Chargeback on deposit ❌
├─ Stolen M-Pesa account ❌
├─ Proxy payment (someone else paid) ❌
└─ FORFEITURE: 100% + Legal action possible

3. IMPERSONATION
├─ Posing as someone else ❌
├─ Using borrowed ID ❌
├─ Family member's account ❌
└─ FORFEITURE: 100% + Account BANNED
```

#### **CATEGORY 2: Customer Harm**

```
1. CHARGEBACK ABUSE
├─ Filing false chargebacks (>2 times) ❌
├─ Disputing legitimate payments ❌
├─ Pattern of fraudulent disputes ❌
└─ FORFEITURE: 50% per chargeback, after 2nd = 100%

2. VIOLENCE / THREATENING BEHAVIOR
├─ Threatening customer ❌
├─ Physical harm to customer ❌
├─ Intimidation ❌
├─ Harassment ❌
└─ FORFEITURE: 100% + Account BANNED + Reporting to police

3. THEFT / PROPERTY DAMAGE
├─ Stealing from customer's home ❌
├─ Intentional property damage ❌
├─ Cheating customer (fake completion) ❌
└─ FORFEITURE: 100% + Legal action
```

#### **CATEGORY 3: Platform Abuse**

```
1. RATING MANIPULATION
├─ Fake positive reviews (>3) ❌
├─ Buying fake reviews ❌
├─ Rating manipulation scheme ❌
├─ Brigading (group fake reviews) ❌
└─ FORFEITURE: 50% first time, 100% second time

2. SEXUAL HARASSMENT / INAPPROPRIATE BEHAVIOR
├─ Sexual harassment of customers ❌
├─ Inappropriate messages ❌
├─ Unwanted advances ❌
└─ FORFEITURE: 100% + Account BANNED + Police report

3. DISCRIMINATION
├─ Refusing service based on race/religion/gender ❌
├─ Discriminatory comments ❌
├─ Prejudicial behavior ❌
└─ FORFEITURE: 100% + Account BANNED
```

#### **CATEGORY 4: Repeated Violations**

```
1. PATTERN OF VIOLATIONS
├─ 3+ customer complaints = Warning #1
├─ 5+ customer complaints = Warning #2
├─ 7+ customer complaints = Account suspended
└─ FORFEITURE: 50% of deposit + Suspension 30 days

2. MULTIPLE DISPUTES (>20% dispute rate)
├─ Dispute rate >20% of jobs ❌
├─ Pattern of false disputes ❌
├─ Systematic chargebacks ❌
└─ FORFEITURE: 50% + Account review

3. POLICY VIOLATIONS (repeated)
├─ Violating service hours (>3 times) = Warning
├─ Cancelling jobs (>5 times) = Suspension
├─ No-show (>3 times) = Ban
└─ FORFEITURE: 25% per violation, escalating
```

### **Forfeiture Decision Process**

```
STEP 1: Violation Detected
├─ Customer reports issue

└─ Investigation triggered

STEP 2: Evidence Collection (24-48h)
├─ Customer statement
├─ Worker statement

STEP 3: Review & Decision (24h)

├─ Reason clearly explained
├─ Amount forfeited: KSh ___

STEP 5: Execution

## 🚫 ACCOUNT SUSPENSION & CLOSURE

### **Suspension (Temporary)**

**When Does Suspension Happen?**
```
AUTOMATIC SUSPENSION:
├─ Account flagged for fraud investigation (48h hold)
├─ Multiple chargebacks filed (pending resolution)
├─ Violence/harassment reported (pending investigation)
├─ Rating drops below 3.0 (30-day warning first)
└─ Deposit forfeiture (30-day minimum)

MANUAL SUSPENSION (By Fixera):
├─ Violation of terms (with notice)
├─ Legal investigation
├─ Regulatory compliance issue
├─ Safety concern
└─ Pattern of abuse
```

**What Happens During Suspension?**
```
Worker CANNOT:
├─ Accept new jobs ✗
├─ Contact customers ✗
├─ View earnings ✗
├─ Make withdrawals ✗
└─ Access platform ✗

Worker CAN:
├─ View suspension reason ✓
├─ File appeal ✓
├─ Contact support ✓
├─ See countdown timer ✓
└─ Receive updates ✓

Deposit Status:
├─ If <24h old: Refunded (no penalty)
├─ If >24h old: Held until suspension resolved
└─ If violation: Forfeited
```

**Suspension Duration**
```
1st Violation: 7-14 days
2nd Violation: 30 days
3rd Violation: 90 days
4th Violation: Permanent ban

Examples:
├─ Low-level violation: 7 days
├─ Moderate violation: 30 days
├─ Serious violation: 90 days
└─ Fraud/Safety: Permanent ban

## ⚖️ DISPUTE RESOLUTION

### **If Worker Disputes Deposit Forfeiture**

**The Process:**

```
STEP 1: Worker Files Dispute
├─ Goes to: Wallet Settings → "Appeal Forfeiture Decision"
├─ Fills form:
│  ├─ Reason for appeal
│  ├─ Additional evidence (photos, messages)
│  └─ Explanation of issue
└─ Submits within 7 days

STEP 2: Evidence Submission
├─ Worker can provide:
│  ├─ Messages with customer
│  ├─ Service completion proof
│  ├─ Photos of completed work
│  ├─ Payment receipts
│  ├─ Witness statements
│  └─ ID verification (if identity disputed)
└─ Deadline: 7 days from dispute filing

STEP 3: Review by Appeals Team
├─ Team: 2-3 people (not original decision makers)
├─ Review: All evidence again
├─ Criteria:
│  ├─ Was original decision fair?
│  ├─ Any new evidence?
│  ├─ Precedent cases?
│  └─ Policy compliance?
└─ Timeline: 5-10 business days

STEP 4: Decision
├─ Options:
│  ├─ UPHOLD forfeiture (original decision stands)
│  ├─ OVERTURN forfeiture (deposit refunded)
│  ├─ PARTIAL refund (e.g., 50% back)
│  └─ SUSPEND forfeiture (pending investigation)
└─ Decision sent via email + in-app

STEP 5: Execution
├─ If overturned: Deposit refunded within 3 days
├─ If upheld: Decision final, no further appeals
├─ If new investigation: Timeline provided
└─ Account status updated
```

**Appeals Decision Criteria:**

```
FACTORS CONSIDERED:
├─ Evidence quality: Does worker have proof?
├─ Customer evidence: Is customer reliable?
├─ Platform records: What do logs show?
├─ Precedent: Similar cases & decisions
├─ Fairness: Is outcome proportionate?
├─ Intent: Did worker intentionally violate?
└─ Repeat offense: First time or pattern?

EXAMPLES:

Case 1: Disputed "Fraud" Forfeiture
├─ Claim: "ID is fake"
├─ Worker provides: National ID, birth cert, passport
├─ Evidence: All documents valid and authentic
├─ Decision: OVERTURN → Deposit refunded
└─ Reasoning: Clear evidence of identity validity

Case 2: Disputed "Chargeback" Forfeiture
├─ Claim: Worker filed false chargeback
├─ Evidence: M-Pesa transaction shows KSh 500 sent
├─ Counter: Worker says payment was stolen
├─ Investigation: M-Pesa confirms legitimate transaction
├─ Decision: UPHOLD → Forfeiture stands (chargeback confirmed)
└─ Reasoning: Transaction legitimate, forfeiture policy clear

Case 3: Disputed "Rating Manipulation" Forfeiture
├─ Claim: 3 fake positive reviews
├─ Worker says: Friends left genuine reviews
├─ Evidence: Reviews same phone IP address
├─ Investigation: IP trace shows different devices
├─ Decision: PARTIAL REFUND → 50% back (KSh 250)
└─ Reasoning: Some evidence of manipulation, but not conclusive
```

## 🔄 APPEALS PROCESS

### **Appeal Levels**

**Level 1: Initial Appeals Team**
```
├─ 2 Fixera team members review
├─ Different from original decision makers
├─ Review all evidence
├─ 5-10 business days
└─ Success rate: ~30% (many decisions are correct)
```

**Level 2: Senior Review Committee**
```
├─ Escalate if Level 1 decision unsatisfactory
├─ 3-member committee (including manager)
├─ Full case review
├─ 10-15 business days
└─ Final decision (no further appeals)
```

**Level 3: External Arbitration**
```
├─ Only for cases with legal implications
├─ Kenya Arbitration Act 1995
├─ Independent arbitrator (mutually agreed)
├─ Costs split 50-50 (if worker wants to pursue)
├─ Final and binding decision
└─ Rare: Only for disputes >KSh 10,000
```

### **Appeal Deadlines**

```
TIME LIMITS:

From forfeiture notice:
├─ Days 1-7: File initial appeal ← DEADLINE
├─ Days 8-30: Appeal review period
├─ Day 31: Decision given
└─ Days 32-37: Escalate to Level 2 (if rejected)

From Level 1 decision:
├─ Days 1-7: Request Level 2 escalation ← DEADLINE
├─ Days 8-25: Level 2 review
└─ Day 26: Final decision

Missing deadlines:
├─ Appeal cannot be filed
├─ Decision stands
└─ No refund possible
```

## 🔧 SPECIAL CIRCUMSTANCES

### **What If Worker Disputes a Job (Unrelated to Deposit)?**

```
SCENARIO: Customer disputes job quality, wants refund
├─ Worker's available balance: KSh 1,500
├─ Dispute amount: KSh 500 job
└─ Question: Can Fixera hold the security deposit?

ANSWER: NO - Security deposit is SEPARATE
├─ Security deposit (KSh 500): Cannot be touched for job disputes
├─ Job earnings (KSh 1,500): Can be held during dispute
└─ Mechanism: Job disputed amount held, deposit stays protected

HOW IT WORKS:
├─ Job disputed: KSh 500 moved to HOLD
├─ Wallet shows:
│  ├─ Deposit: KSh 500 (untouched)
│  ├─ Available: KSh 1,000 (KSh 500 moved to hold)
│  ├─ On Hold: KSh 500 (job dispute)
│  └─ Total: KSh 2,000
├─ Investigation happens
├─ If worker wins: KSh 500 released back to available
├─ If customer wins: KSh 500 refunded to customer
└─ Deposit (KSh 500): Still protected, not used
```

### **What If Worker Downgrades to Tier 1?**

```
SCENARIO: Worker had Tier 2 (KSh 1,000 deposit), wants to downgrade

RULES:
├─ Can downgrade anytime
├─ Refund difference: KSh 500 (1,000 - 500)
├─ Lose Tier 2 benefits
├─ Can upgrade back later (pay additional KSh 500)

PROCESS:
├─ Worker: Settings → "Downgrade to Tier 1"
├─ Confirms decision
├─ System: Returns KSh 500 via M-Pesa
└─ Status: Tier 1 (KSh 500 deposit) activated

TIMING:
├─ Downgrade processed immediately
├─ M-Pesa refund within 24h
└─ Benefits end immediately
```

### **What If Worker Has Outstanding Debt?**

```
SCENARIO: Worker owes Fixera (fraud refund paid to customer), 
account later charged

RULES:
├─ Fixera CAN offset deposit against debt
├─ But ONLY if clear terms in contract
├─ Worker must be given 30-day notice
├─ Worker gets chance to pay debt directly

PROCESS:
├─ Fixera: Detects debt (e.g., KSh 2,000 owed)
├─ Notice sent: "You owe KSh 2,000, pay by [date]"
├─ Options:
│  ├─ Option 1: Worker pays KSh 2,000 directly
│  ├─ Option 2: Fixera offsets KSh 500 deposit + KSh 1,500 future earnings
│  └─ Option 3: Worker payment plan (e.g., KSh 500/week)
└─ If not paid: Offset happens, deposit used

DEPOSIT USED FOR DEBT:
├─ Only if worker doesn't respond to notice
├─ Deposit goes toward debt, not forfeited as punishment
├─ Remaining debt still owed (KSh 1,500)
└─ Account continues operating (doesn't close)
```

### **What If Payment Fails (Chargeback)?**

```
SCENARIO: M-Pesa reverses deposit (chargeback/fraud)

TIMELINE:
├─ Day 0: Deposit paid
├─ Days 1-5: Fixera holds deposit
├─ Day 6: M-Pesa initiates reversal (chargeback)
├─ Days 6-10: Dispute period
└─ Day 11: Reversal completes

FIXERA'S RESPONSE:
├─ If reversal is legitimate (stolen phone, etc.):
│  └─ Account closed, no penalty to worker
├─ If reversal is fraud by worker:
│  ├─ Account BANNED
│  ├─ Reported to M-Pesa
│  └─ Possible legal action

WORKER'S WALLET:
├─ If legitimate reversal: Wallet closed, refund issued
├─ If fraudulent reversal: Wallet banned, no refund
└─ Jobs done: May still be paid (investigation determines)
```

### **What If Worker is Injured/Dies?**

```
SCENARIO: Worker cannot continue (injury, death, etc.)

DEATH:
├─ Family can provide death certificate
├─ Wallet closed
├─ Deposit refunded to estate/beneficiary (with proof)
